Exact objective and endpoint semantics 
L_geometry = mean((u uᵀ - Y)²) + λ mean((u a - ρ)²)
L_catch    = α mean(1 - cos(u, stopgrad(z)))
           + (1 - α) mean(1 - cos(stopgrad(u), z))
L          = L_geometry + 0.1 L_catch

α=1 freezes the sequence map after least-squares initialization while the learned vectors move toward it. α=0 routes catch pressure only into the sequence map while empirical geometry continues to update the learned table.

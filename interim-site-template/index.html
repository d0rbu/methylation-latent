Interactive spherical latent geometry

Deterministic exact-Torch UMAP onto the unit two-sphere for the full models at λ = 0.1 and d = 16, 32, 64, 128. Both high-dimensional neighbor distances and three-dimensional output distances are intrinsic sphere geodesics, acos(clamp(zᵢ·zⱼ)). Every panel uses the same 300 validation loci, balanced to 75 per genomic context, plus the normalized learned age direction as a separately marked point. No test loci or targets enter these projections. The color selector exposes the same six locus annotations as the age scatter.

Drag to rotate each sphere; scroll or use +/− to zoom; double-click or press R to reset. Reducing Sd−1 to S² is necessarily lossy, so every panel reports geodesic stress, all-pair geodesic-distance correlation, and 14-neighbor recall. Axis orientation is arbitrary. These panels are descriptive, not a model-selection metric.
